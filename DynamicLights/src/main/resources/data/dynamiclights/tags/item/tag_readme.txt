dynamic lights tagging examples using minecraft datapack API

dropped.json tags contained items with dynamiclights:dropped which is then used with the default max/15 light value for contained IDs
dropped_8.json is the same, except using a light value of 8 instead of the 15 default
not_waterproof is tagging ID which should have dynamic light toggle off in water
the dropped tag works for the "dropped items light" module, and the self tag works for items carried or equipped
